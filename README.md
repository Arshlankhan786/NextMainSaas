## 🎯 What is Next Academy?
Next Academy is a comprehensive, AI-powered Educational CRM (Customer Relationship Management) and LMS (Learning Management System) built with procedural PHP and MySQL. It serves as a unified platform for **Next Academy in Kalol**. 

### 💡 The Problem it Solves
Managing an educational institute often involves juggling multiple disconnected tools for student enrollment, fee tracking, attendance, assignment grading, and event management. Next Academy solves this by providing a **single, unified portal** that bridges the gap between administration, learning, and public outreach. It ensures:
- **For Students:** Easy access to course materials, real-time typing competitions, project submissions, attendance tracking, and transparent performance leaderboards.
- **For Administration:** Streamlined operations including fee collection, overdue reminders, course management, student status tracking (Active, Hold, Completed), and automated analytics.
- **For the Public:** A modern, dynamic website showcasing courses (like Digital Marketing, Full Stack, and AI), events, and academy highlights to attract new enrollments.

---

## ✨ Key Features

This SaaS platform is divided into three core interconnected modules, offering an end-to-end solution for institute management:

### 🌍 1. Public Website & Lead Generation
- **Dynamic Homepage:** Features a smart, database-driven Activity Calendar and vibrant course highlights.
- **Comprehensive Course Catalog:** Explore specialized, detailed landing pages for courses like Digital Marketing Pro, MERN Stack Development, and Backend Mastery.
- **Inquiry & Lead Management:** Built-in contact forms and direct admission inquiry handling.
- **Photo Gallery:** Showcase academy events, infrastructure, and student life.

### 🛡️ 2. Admin Panel (CRM & Operations)
- **Student Lifecycle Management:** Manage registrations, profile updates, batch assignments (Morning/Evening), study groups, and dynamically track statuses (Active, Hold, Dropped, Completed).
- **Finance & Accounting System:** Track student fee payments, generate automatic receipts, track institute expenses, and automatically calculate pending/overdue students.
- **Assessment & Test Engine:** Create dynamic MCQ quizzes, assign tests to specific students or batches, and monitor real-time typing competition results.
- **Task & Project Verification:** Assign daily/weekly tasks, manage manual crons, and review/approve student project submissions (with point awards).
- **Event & Activity Management:** Schedule upcoming events, track student participation, and manage the monthly activity calendar.
- **Dynamic Leaderboard System:** Automatically calculates and ranks students based on a points system aggregated from tests, projects, and manual awards.
- **Analytics Dashboard:** Rich visual charts (via Chart.js) providing insights into attendance rates, financial health, and overall academy performance.
- **Role-Based Access Control (RBAC):** Secure access tiers including Super Admin, Admin, Administrator, and HR.

### 🎓 3. Student Portal (LMS Experience)
- **Interactive Dashboard:** A personalized hub showing attendance percentage, pending fees, upcoming tasks, and current leaderboard ranking.
- **Attendance Tracking:** Self-service daily check-in/check-out system (automatically excludes Sundays/holidays).
- **Learning & Assessments:** Participate in live online quizzes with real-time auto-saving, view detailed quiz results, and practice in typing competitions.
- **Project Submission Hub:** Easily upload project links and files for admin review and grading.
- **Activity & Event History:** Track past participation in academy events and view upcoming scheduled activities.
- **Finance Tracking:** Transparent view of payment history, fee structures, and receipt downloading.

## 🏗️ Architecture & Tech Stack
- **Backend:** Procedural Server-Rendered PHP.
- **Database:** MySQL/MariaDB (via `mysqli` with prepared statements for security).
- **Frontend:** HTML5, CSS3, JavaScript, and Bootstrap 5 (Dark Mode SaaS aesthetic).
- **Authentication:** Native PHP `$_SESSION` with strict role-based access control (Super Admin, Admin, Student).
