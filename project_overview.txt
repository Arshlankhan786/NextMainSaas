# Project Overview: NextMain
This is a comprehensive PHP-based web application containing both a public-facing website, an administration panel, and a student portal. It is likely an educational or institute management system (possibly for a digital marketing or tech academy).

## Key Components

### 1. Public Website
- **Pages**: `index.php`, `about.php`, `contact.php`, `courses.php`, `gallery.php`, `digital-marketing.php`, `digital-marketing-dark.php`
- **Purpose**: Provides public information about the academy, courses offered (like Digital Marketing, Full Stack, AI), and handles inquiries.

### 2. Admin Panel (`/admin`)
- **Core Functionality**: Managing the institute's operations.
- **Key Modules**:
  - Student Management: `students.php`, `student_details.php`, `student_groups.php`, `hold_students.php`, `past_students.php`
  - Course & Topic Management: `courses.php`, `categories.php`
  - Assessment & Tasks: `task_manager.php`, `assign_test.php`, `create_test.php`, `typing_results.php`
  - Finance: `payments.php`, `add_payment.php`, `expenses.php`, `receipt.php`
  - Analytics & Reports: `reports.php`, `student_analytics.php`, `attendance_report.php`
  - Configuration/Auth: `login.php`, `settings.php`, `admins.php`

### 3. Student Portal (`/student`)
- **Core Functionality**: Portal for enrolled students.
- **Key Modules**:
  - Dashboard & Profile: `dashboard.php`, `profile.php`
  - Learning & Assessment: `projects.php`, `take_quiz.php`, `quiz_result.php`, `my_tests.php`, `typing_competition.php`
  - Tasks & Progress: `task_manager.php`, `attendance.php`
  - Finance: `payments.php`, `receipts.php`

### 4. API / AJAX Endpoints
- **Admin AJAX (`/admin/ajax`)**: Scripts for dynamic operations like `manage_projects.php`, `student_analytics_data.php`, `fetch_test_assignments.php`.
- **Student AJAX (`/student/ajax`)**: Scripts for quiz submissions (`submit_quiz.php`), saving typing results, etc.

### 5. Config & Includes
- **`/admin/config`**: Database credentials, email settings, and auth configuration.
- **`/includes`**: Shared UI elements (navbar, footer, splash-screen).
- **`/admin/includes` & `/student/includes`**: Portal-specific headers and footers.
